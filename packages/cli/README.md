# likec4-agent

Deterministic CLI that syncs a [LikeC4](https://likec4.dev) architecture
model from `@likec4` / `@likec4-rel` code annotations.

Full reference (installing, flags, exit codes):
[`docs/cli-reference.md`](https://github.com/dilzio/likec4-annotations/blob/main/docs/cli-reference.md)
in the [likec4-annotations](https://github.com/dilzio/likec4-annotations)
repo.
